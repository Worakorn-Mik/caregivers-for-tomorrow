# app/

โค้ดแอปพลิเคชัน Caregivers For Tomorrow

## ยังไม่เลือก tech stack

ทีมตัดสินใจร่วมกันก่อน แล้วเติมตรงนี้ + ที่ `CLAUDE.md` ข้อ 4

**ข้อกำหนดจาก business proposal:**
- ต้องขึ้น Play Store (ค่าขึ้นแอป one-time อยู่ในงบ Phase-2)
- มี frontend (แอปมือถือ) + backend (API) + cloud server (งบจำกัด ~1,000–1,200 บาท/phase)
- ฟีเจอร์แกน: จับคู่ผู้ดูแล-ผู้ใช้, เลือกระดับผู้ดูแล (Tiering), จอง/จ่ายรายชั่วโมง,
  ตรวจประวัติ + ใบประกอบวิชาชีพ, รีวิว/ให้คะแนน 2 ทาง, check-in/out + GPS

**ตัวเลือกที่สมเหตุสมผลสำหรับทีมนักเรียน:**
- Mobile: React Native (Expo) หรือ Flutter
- Backend: อะไรก็ได้ที่ทีมถนัด + host ถูก (เช่น Node/Express, FastAPI, หรือ Firebase/Supabase ลดงาน backend)

เมื่อเลือกแล้ว: scaffold โปรเจกต์ในโฟลเดอร์นี้ แล้วอัปเดต `../README.md` ส่วน "เริ่มงาน"
