# research/

งานค้นคว้า/ข้อมูลดิบทั้งหมดที่ใช้สนับสนุนแผนรอบ 2 — track เท่ากับ code

| โฟลเดอร์ | ใส่อะไร | ผูกกับ action plan ข้อ |
|---|---|---|
| `legal/` | บันทึกปรึกษ ากฎหมาย/สภาการพยาบาล, list งานที่ทำได้/ห้าม, ข้อความ พ.ร.บ. ที่เกี่ยวข้อง | 1 |
| `segments/` | การแบ่ง segment ผู้ป่วย (ช่วยเหลือตัวเองได้ / ติดเตียง), map ความต้องการ→สิ่งที่ผู้ดูแลทำได้ | 2 |
| `competitor-analysis/` | ตารางเทียบคู่แข่ง (Health Delivery พา, VNurseCare, CareGiver.in.th, เอเจนซี่) | 4 |
| `user-research/` | ผล survey 200 ครัวเรือน + 50 ผู้ให้บริการ, บันทึกสัมภาษณ์/ตามติดผู้สูงอายุ, ผล pilot | 6 |
| `unit-economics/` | take rate, งาน/ผู้ให้บริการ/เดือน ที่ break-even, CAC, map เข้ากับงบ Phase-1/2 | 6 |

ไฟล์ raw (CSV, ภาพถ่ายแบบสอบถาม, สเปรดชีต) วางในโฟลเดอร์ย่อยได้เลย
แต่ละหัวข้อควรมีไฟล์สรุป `.md` 1 ไฟล์ที่ชี้ว่า "เราสรุปได้ว่าอะไร"
